# MedClinic API - Etapa 1-2: Setup criação as pastas

## Objetivo
Criar pastas estruturadas para o projeto.

## Estrutura de Pastas Obrigatória (Devem ser criadas como DIRETÓRIOS)
O agente deve criar a seguinte árvore de diretórios vazios dentro da pasta `src/`:
- `src/database/` (Diretório para configurações do banco de dados)
- `src/entities/` (Diretório para os modelos/entidades do TypeORM)
- `src/repositories/` (Diretório para as classes de persistência)
- `src/services/` (Diretório para as regras de negócio)
- `src/controllers/` (Diretório para os controladores de rotas)
- `src/middlewares/` (Diretório para os intermediadores de requisição)
- `src/routes/` (Diretório para definição dos endpoints)
- `src/utils/` (Diretório para funções auxiliares comuns)
